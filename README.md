# AgroFlow

Projeto web do AgroFlow organizado em React, com navegação entre páginas, avaliação de saúde do cultivo, simulador de economia agrícola e formulário de contato.

## Requisitos

Node.js 18 ou superior e pnpm instalado.

## Execução local

```bash
pnpm install
pnpm run dev
```

A aplicação ficará disponível no endereço informado pelo Vite.

## Verificação e build

```bash
pnpm run check
pnpm run build
```
